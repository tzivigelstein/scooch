# Third-party notices

Scooch's own code is licensed under the terms in [LICENSE](LICENSE). The app
built from it (`yarn build`, in `dist/`) also contains the third-party software
listed here, each under its own license. The license texts follow the table.

What this covers: everything that ships to the browser. That is the npm
packages whose modules end up in the production bundle, the files copied into
it as they are (the pdf.js worker and the Inter and Noto Sans Devanagari font
files) and the small
helpers the build tools add. Development tools that don't ship (Vitest,
Playwright, TypeScript, jsdom…) are not listed.

Versions are the ones locked in `yarn.lock`. Licenses, copyright lines and
links are as read from each installed package: its `package.json`, its license
file and, where the license file has no copyright line, the package's own file
headers.

  Vite's own Node.js tooling, which doesn't ship to the browser; only Vite's
  own license is reproduced below.

## How to update this file

When a runtime dependency is added, removed or upgraded, check what the
production bundle contains and update the table and the texts. One way, without
touching the project's config, is to build with source maps into a temporary
folder and list the `node_modules` packages in the maps:

```sh
yarn vite build --sourcemap --outDir /tmp/scooch-map --emptyOutDir
```

Files copied as they are (such as the pdf.js worker and the fonts) don't show up
in the maps; look at `dist/assets/` for them.
