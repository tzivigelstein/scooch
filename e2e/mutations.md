# Mutation log

Before a group of old browser checks was replaced, the product code it guarded
was broken with a one-line mutation in a throwaway copy of the repository
(never in the working tree), and the new tests had to fail. «CAUGHT» means they
did; a mutation that survived led to a stronger test (noted in its row) or is
explained as equivalent or not guarded. See docs/testing.md.

338 mutations recorded.
